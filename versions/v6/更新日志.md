# v6 · 星云纪元（0.7.29-custom.6 / versionCode 536）

> 在 v5 基础上**增量叠加**，v5 全部文件与能力完整保留；原 v5 工程包与 APK 未删除。

## 启动页
- 新增**星云**样式为默认：折射玻璃核、三层倾斜轨道、conic 光环、三条流星拖尾、标题逐字浮现、光带进度
- 原「液态玻璃」「3D 晶体」两套完整保留，三态可切；支持「重播启动动画」
- 纯 CSS + 2D canvas 星尘，不用 WebGL；减少动态效果、跳过动画、12 秒兜底均保留

## 新增功能
- 主题预设收藏夹：命名保存 / 一键切回 / 删除整套外观
- 五组细腻调节：界面密度、精致度、字距、字重、微动效强度
- 流光强调色（单条 CSS 变量驱动，零逐帧 blur）、静谧模式、低对比文字提亮
- 低电量自动省电（Battery Status，不支持则静默跳过）
- 启动耗时 / 实时帧率读数、复制诊断、更新日志面板、恢复 v6 默认（不动用户数据）
- 左下角可拖动 ✦ 徽标：点击开面板，长按 600ms 切静谧，位置记忆

## 更流畅
- 零常驻 `backdrop-filter`；装饰全部静态渐变 + `transform/opacity`
- 初始化按 `requestIdleCallback` 分三批；监听全部 passive
- 离屏装饰动画由 IntersectionObserver 暂停；长列表 `content-visibility`
- 低帧三级自适应降级：连续 3 次 < 42 FPS → 关流光 → 收精致度 → 收微动效 + 静谧
- 低对比文字扫描命中即停，最多 48 个元素，12 秒后强制断开

## 保留
v5 的液态玻璃主题、7 套配色、强调色循环、主题自动轮换、主题分享码、听歌计时、三档性能、实时帧率面板、自动性能档、一键极速、设置备份恢复、可拖动悬浮球、复制诊断、3D 环境光效、空状态引导卡片，全部保留。
